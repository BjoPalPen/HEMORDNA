Familjen Grotesk (familjen-grotesk.woff2)

Copyright 2021 The Familjen Grotesk Project Authors. Licensed under the SIL
Open Font License, Version 1.1 - see OFL-FamiljenGrotesk.txt.

Variable font (weight axis 400-700), fetched via the Google Fonts CSS2 API
(the "latin" subset, which covers Swedish å/ä/ö - U+0000-00FF) from:
https://fonts.gstatic.com/s/familjengrotesk/v11/Qw3GZR9ZHiDnImG6-NEMQ41wby8WbHoEjw.woff2

One file serves all four weights used in the app (400/500/600/700) - each
@font-face in app.css declares a single font-weight against the same file,
and the browser renders the correct instance via the file's own variable
weight axis.
