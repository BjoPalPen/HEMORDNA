## Läge

`main` är pushad och kodrelease `21410b4` deployad till https://app.hemordna.se. Elva
releaser (PR #11–#21) sedan `4f913ce`. Första releasen med en riktig datamigrering.

- **`Area` har nu ett riktigt `Floor`-fält**, oberoende av `Name`. "Våning" var tidigare bara
  en namnkonvention ("Våning 1 – Kök"), vilket gjorde det omöjligt att flytta ett rum mellan
  våningar eller återanvända ett våningsnamn utan att stava exakt rätt. Migreringen
  `AddFloorToArea` packar upp BEFINTLIGA rum automatiskt (Björns beslut): SQL körd och
  bekräftad i produktionsloggen – `ALTER TABLE` + `UPDATE ... SET "Floor" = split_part(...)`
  mot riktiga `Areas`-rader. Unikhetsregeln för rumsnamn är nu per `(Floor, Name)`, inte
  `Name` ensam – annars hade två likadant namngivna rum på olika våningar blivit en
  regression. Två UX-flöden: "Nytt rum" föreslår befintliga våningsnamn, ny åtgärd "Flytta
  till våning". Dold bugg hittad och fixad: Idag-sidans rumsgruppering på bara `AreaName`
  hade kunnat slå ihop två olika rum med samma namn på olika våningar. Se ARCHITECTURE.md
  "Beslut: Riktigt Floor-fält på Area".

## Köra och deploya

Uppstart: [../README.md](../README.md). API `5199`, klient `5200`, Postgres `5432`.
Docker Desktop måste köra för lokal API/E2E. LAN: `--urls "http://*:PORT"`.
Server: `ssh -i ~/.ssh/hetzner_deploy deploy@62.238.45.45`, checkout `~/hemordna`.
Deploy: `git pull --ff-only origin main`, sedan
`docker compose -f docker-compose.prod.yml up -d --build --no-deps hemordna-api` – migrationer
körs automatiskt vid uppstart, kontrollera `docker logs hemordna-api` efter en schemaändring.
En ofarlig `libgssapi_krb5.so.2`-varning syns vid varje uppstart (Npgsql/Kerberos-sondering,
inte kopplad till migreringar) – ignorera den.
Browserkontroll: `dotnet run --project scripts/Smoke -- https://app.hemordna.se`.

## Drift och kvarstående frågor

Ingen rollback-tagg togs före dessa releaser – tagga `hemordna-hemordna-api:latest` som
`rollback-before-<sha>` innan nästa deploy. Migreringens `Down()` återskapar INTE Floor+Name –
en rollback efter denna release kräver extra eftertanke, inte bara en vanlig nedmigrering.
Två kända, orelaterade E2E-flakes kvarstår outredda: `SkarmbilderTests`, `EnergyTests`.
Två öppna beslut: "Tid i förväg"-etiketten, och en gles Heavy-uppgift i ett sammanslaget
besök (storstäd-releasen). Två föråldrade ARCHITECTURE.md-referenser kring rad ~795/~1214
(borttaget testnamn/`RoomFloors.cs`) – flaggade, inte rättade.
